## Vision

**bala-weave is the connective tissue.**

This repository holds the contribution infrastructure for the entire new world: pull-request templates, issue templates, good-first-issue labels, and collab guidelines. Any repo in the Balamonis world can point contributors here to learn how to weave their work in.

We welcome contributions. We review them in public. We credit them in public.

---

## How to contribute

1. **Find a repo** in the `bala-nexus` world map that interests you.
2. **Read its `AGENTS.md`** — that's the local operating manual.
3. **Pick a good-first-issue** (labeled `good first issue` in any repo) or open a new one.
4. **Branch from `main`**, make your change, write a clear commit message.
5. **Open a PR** using the template below. It will be reviewed in `bala-voice`.

---

## Pull request template

```
## What
One sentence: what this changes and why.

## Which repo
The repo this PR targets (e.g. bala-nexus, AI-Job-Automation).

## Connection
Which other repo or venture does this touch? (per bala-nexus map)

## Checks
- [ ] Branch created from `main`
- [ ] Commit message is clear (type(scope): description)
- [ ] Tests pass (if any exist)
- [ ] Truthful claims only — no fabricated metrics
- [ ] ROADMAP.md and backlog/priorities.md updated if scope changed
```

## Issue template

```
## What
One sentence: what you're proposing or reporting.

## Which repo
The repo this relates to.

## Priority
[NOW] / [NEXT] / [LATER] / [PARKED]

## Connection
Which other repo or venture does this touch?

## Next step
What should happen next, and who can do it?
```

## Good-first-issue areas

- Documentation improvements in any repo
- Typos, broken links, clarity fixes in READMEs
- Adding a repo to the `bala-nexus` world map
- Translating a page or doc
- Writing a first test for a repo that lacks one

## Working rules

- **Work on a branch, never `main`.** Small commits with clear messages.
- **Truthful claims only.** No fabricated contribution metrics or response-time promises beyond what's in `bala-voice`.
- **Before ending a session:** update `ROADMAP.md`, `backlog/priorities.md`, append to `reports/LOG.md`.

---

## Getting started

1. Read `AGENTS.md`.
2. Browse `bala-nexus` for a repo to contribute to.
3. Pick a good-first-issue or open one.
4. Branch, commit, PR using the template above.
