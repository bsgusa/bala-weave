# AGENTS.md — bsgusa / bala-weave (collab + contributions)

Conventions for AI agents (and humans) working in this repo.

## Start here

1. Read [`ROADMAP.md`](./ROADMAP.md) — milestones; work the `[NOW]` item.
2. Read [`backlog/priorities.md`](./backlog/priorities.md) — the detailed task list.
3. Skim the latest file in [`reports/`](./reports/) for recent context.

## Purpose

`bala-weave` is the connective tissue — PR templates, issue templates, good-first-issue labels, and collab guidelines for the whole Balamonis new world.

## Layout

| Path | What lives there |
|---|---|
| `.github/PULL_REQUEST_TEMPLATE.md` | Standard PR template for all repos |
| `.github/ISSUE_TEMPLATE/` | Structured issue templates |
| `docs/CONTRIBUTING.md` | End-to-end: find repo → read AGENTS.md → pick issue → branch → PR |
| `docs/GOOD_FIRST_ISSUES.md` | Curated starter issues per repo |
| `reports/` | Dated build logs + contributor credit log |
| `ROADMAP.md` / `backlog/priorities.md` | Milestones + task list |

## Working rules

- **Work on a branch, never `main`.** Small commits with clear messages.
- **Truthful claims only.** No fabricated contribution metrics or response-time promises beyond `bala-voice`.
- **Labels:** `good first issue`, `help wanted`, `collab`, `trending-signal`.
- **Before ending a session:** update `ROADMAP.md`, `backlog/priorities.md`, append to `reports/LOG.md`.

## Stack

Markdown + YAML + GitHub templates. No build step.

## GitHub

Org: `bsgusa`. Repo: public. Issues = contribution templates. PRs = improve the templates themselves.
